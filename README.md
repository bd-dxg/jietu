# jietu

轻量原生截图与标注工具，面向 Windows 11 无独显迷你主机（仅 CPU 核显）。纯 CPU 渲染，常驻几乎零开销，触发即用。

> 当前状态：**M0 骨架**（Cargo 工程 + 模块占位 + 领域文档），尚未实现功能。见下文路线图。

## 特性规划

- 托盘常驻 + 全局热键（F1 截图 / F3 贴图，可自定义）
- 全屏冻结抓取、框选、八向缩放、多显示器混合 DPI
- 矢量标注：矩形、直线/曲线箭头、文本（中文 IME）、高斯模糊、高亮
- 输出到剪贴板（CF_DIB + PNG）/ 保存 PNG / JPEG / WebP
- 长截图：自动/手动滚动、条带拼接、固定区域识别
- 贴图（Pin）：任意截图钉在屏幕，缩放、透明度、点击穿透
- 二期：OCR / 翻译（Provider 抽象 + 本地 Windows.Media.Ocr 备选）、渐变样式

## 构建

```powershell
# 检查编译
cargo check

# 发布版（单文件，目标 ≤ 5 MB）
cargo build --release
```

依赖：Rust 1.98（edition 2024）、windows-rs 0.62、tiny-skia 0.12、serde、toml、png。
